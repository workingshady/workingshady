## 🛠️ What I build

- **On-device vision**: making segmentation and tracking models small and fast enough to run on a phone.
- **LLM agents**: LangChain and LangGraph pipelines that take real actions.
- **Data tooling**: scrapers and quality checkers that turn messy sources into clean, versioned data.
- **Full-stack products**: from model to a deployed app people can actually use.
